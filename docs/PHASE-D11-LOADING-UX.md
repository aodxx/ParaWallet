# Phase D11 — Loading UX and Visual Hierarchy

Backend release remains `2026.08.24-phase-d10`. This phase changes only the GitHub Pages PWA and does not require an Apps Script deployment or schema migration.

## Source evidence

The supplied `loading.lottie (2).zip` is a valid dotLottie archive generated by LottieFiles. Its animation is 124×124 pixels, 15 fps, 31 frames, vector-only, and has no external image assets.

## Changes

- The supplied animation is used for initial account verification, page refresh/navigation, Sale receipt evidence, and Settlement slip evidence.
- The animation and the pinned `lottie-web` light SVG renderer are stored locally and pre-cached by the service worker. No runtime CDN is required. The vendored renderer retains its MIT license notice.
- Long, small loading paragraphs are replaced with a short title and one supporting line in a dedicated loading card or overlay.
- A page stage keeps loading and loaded content in one stable grid. While loading, underlying content is hidden rather than visibly overlapping the loader.
- The completed screen enters once with a short opacity/position transition. Reduced-motion preferences disable the transition and autoplay.
- Mobile heading, metric, panel, and list typography now use distinct sizes and weights so labels, amounts, and supporting text scan in the intended order.
- Main content, page headings, cards, and loader states share consistent grid alignment and spacing.
