# ParaWallet Google Sheets Data Model

Each tab has a stable header row. IDs are UUID strings generated by Apps Script. Timestamps are ISO-8601 strings in Asia/Bangkok display context but should be written consistently by Apps Script. Financial values use decimal numbers rounded to two places by the server calculator.

| Tab | Purpose | Key columns |
|---|---|---|
| Users | Identity and role directory | id, email, name, role, status |
| Gardens | Owner-managed rubber gardens | id, ownerId, name, province, district, areaRai, treeCount, status |
| GardenMembers | Active Owner/Tapper membership | id, gardenId, userId, role, status |
| Agreements | Versioned revenue rules | id, gardenId, ownerId, tapperId, version, ownerPercentage, tapperPercentage, effectiveFrom, effectiveTo, status |
| Sales | Immutable sale and split snapshot | id, gardenId, agreementId, tapperId, saleDate, buyerName, productType, weightKg, unitPrice, grossSale, deductions, splitBase, ownerShare, tapperShare, status |
| Payments | Partial transfers and confirmation | id, gardenId, saleId, fromUserId, toUserId, amount, method, reference, proofFileId, status, paidAt |
| WalletTransactions | Derived ledger movements | id, gardenId, userId, type, amount, sourceType, sourceId, requestId |
| Notifications | User-visible events | id, userId, type, title, body, readAt |
| AuditLogs | Traceability | id, actorId, entityType, entityId, action, beforeJson, afterJson, requestId |
| Requests | Durable idempotency record | requestId, action, status, responseJson, createdAt |
| OcrRecords | OCR provider output and review status | id, fileId, provider, status, confidence, rawJson, reviewedBy |
| Files | Drive metadata only | id, driveFileId, folderType, mimeType, name, ownerId |

A sale stores the agreement ID and the exact percentages used at creation time. Later agreement versions therefore cannot mutate historical sale calculations. Wallet balances are derived from confirmed sales and confirmed payments, with WalletTransactions providing an auditable movement trail.
